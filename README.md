# 🌍 Country Search App

🌐 Live Demo : 

(https://vitesh-webdeveloper.github.io/day-25-country-search-app/)

## 🚀 Features

* Search any country
* Displays flag, capital, population, and region
* Loading, error, and no result states

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript (Fetch API)

## 🔗 API Used

REST Countries API

## 📚 What I Learned

* Working with a different API structure
* Handling nested data (arrays, objects)
* Reusing application architecture
